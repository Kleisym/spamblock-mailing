# Telegram Spambuster

Юзербот на Python (Telethon), созданный для тех, кто сидит в десятках чатов пиара, админских беседках и рекламных биржах Telegram.

Если ты хоть раз оставлял объявления в таких чатах, ты знаешь эту боль:
1. Телефон разрывается от спам-ботов со скупкой звёзд, голды и тона, которые тегают всех подряд через скрытые символы.
2. Админ-боты при входе требуют подписаться на пять левых каналов, чтобы просто отправить одно сообщение.
3. Рассылать свои рекламные посты руками каждые 15 минут — адски надоедает, а обычные автопостеры часто ломают форматирование, не умеют в Telegram Premium эмодзи или палятся чат-фильтрами.

Этот юзербот закрывает все эти вопросы и работает в фоне 24/7.

---

## Что умеет юзербот

- **Глушит спам-теги**: когда бот вроде NINJA или Jrvsu тегает тебя в чате, скрипт моментально сбрасывает статус упоминания на серверах Telegram. Телефон не вибрирует, кружок `@` пропадает сразу.
- **Не пропускает клиентов**: если тебе пишет реальный человек с вопросом («почем реклама?», «актуально?», «стата в лс»), бот понимает контекст и **не** трогает диалог. Ты не потеряешь лид.
- **Сам обходит капчи админ-ботов**: если для отправки сообщений бот требует подписаться на каналы, юзербот сам подпишется, закинет их в отдельную папку `автосабнутое`, замьютит навсегда и нажмет инлайн-кнопку проверки.
- **Гибкая рассылка постов**:
  - **По таймеру**: например, каждые 30 секунд, каждые 10 минут или раз в 2 часа.
  - **По счетчику живых сообщений**: отправляет твой пост только тогда, когда в чате написали N сообщений другие участники (чтобы не спамить в мертвые чаты и не ловить варны).
  - **По папкам Telegram**: можно одной командой запустить рассылку сразу по всей папке чатов (например, `"Пиар"`).
- **Сохраняет 100% разметки и Premium-фишек**: цитаты, скрытый текст под спойлером, зачеркивания, жирный текст, альбомы до 10 медиафайлов и кастомные анимированные эмодзи Telegram Premium.
- **Рассылка пересланных сообщений (`.рассыл-пересланное`)**: умеет рассылать посты прямо из твоего канала с сохранением кликабельной шапки канала и счетчика просмотров. Если пересылка в чате запрещена — бот сам отправит локальную копию поста.
- **Рассылка пачки постов (`.рассыл-несколько`)**: можно зарядить сразу 2–3 сообщения подряд за один цикл (например, текст + прайс-лист картинкой + контакты).
- **Ротация постов (`.чередовать`)**: чтобы чат не забивался одним и тем же креативом, бот может пускать разные посты по кругу (`пост1 ➔ пост2 ➔ пост3`).
- **Мульти-аккаунт в одном процессе**: можно подключить сразу несколько Telegram аккаунтов (`[account1]`, `[account2]` и т.д.). Они работают параллельно и делят общую базу шаблонов.
- **Тихий терминал**: никакого мусора в консоли. Выводятся только стартовый баннер и реальные ошибки/флудвейты.
- **Работает 24/7**: в комплекте лежат готовые скрипты автозапуска для Windows (без висящего черного окна), Linux (systemd служба) и Android (APK-приложение с WakeLock и автостартом после перезагрузки).

## Где взять API ID и API Hash

Для подключения к официальному API Telegram нужны ключи приложения. Делается это один раз за две минуты:

1. Зайди на сайт **[my.telegram.org](https://my.telegram.org)**.
2. Введи свой номер телефона с кодом страны (например, `+79991234567`) и нажми **Next**.
3. В Telegram придет код от официального сервиса — введи его на сайте и нажми **Sign In**.
4. Нажми на раздел **API development tools**.
5. Заполни поля (на английском, любые слова):
   - **App title**: например, `Spambuster`
   - **Short name**: например, `spambuster`
   Остальные строки можно оставить пустыми.
6. Жми **Create application**.
7. Скопируй полученные `App api_id` и `App api_hash`.

## Установка и запуск (Windows / Linux / macOS)

Нужен Python 3.10 или новее.

```bash
# 1. Клонируем проект
git clone https://github.com/Kleisym/spamblock-mailing.git
cd spamblock-mailing

# 2. Создаем виртуальное окружение
python -m venv venv

# 3. Активируем его:
# на Windows:
venv\Scripts\activate
# на Linux / macOS:
source venv/bin/activate

# 4. Ставим зависимость (telethon)
pip install -r requirements.txt
```

### Настройка `config.txt`

Скопируй файл примера:
- Windows: `copy config.example.txt config.txt`
- Linux / Mac: `cp config.example.txt config.txt`

И впиши свои данные.

#### Если у тебя один аккаунт:
```ini
log_errors_only = true

api_id = 12345678
api_hash = 0123456789abcdef0123456789abcdef
phone = +79991234567

session_name = session_userbot
auto_sub_folder = автосабнутое
auto_read_spam_pings = true
auto_sub_enabled = true
```

#### Если хочешь запустить сразу несколько аккаунтов:
```ini
log_errors_only = true

[account1]
api_id = 12345678
api_hash = 0123456789abcdef0123456789abcdef
phone = +79991112233
session_name = session_acc1

[account2]
api_id = 87654321
api_hash = fedcba9876543210fedcba9876543210
phone = +79994445566
session_name = session_acc2
```

### Первый старт

Запусти бота:
```bash
python bot.py
```
- Введи код подтверждения из Telegram.
- Если на аккаунте стоит облачный пароль (2FA), скрипт сам это поймет и попросит ввести пароль.
- Создастся файл `.session`. Больше логиниться не придется — при следующих запусках бот входит мгновенно.

## Как управлять ботом через Telegram

Все команды пишутся прямо в Telegram с того аккаунта, на котором запущен бот. Можно писать в целевом чате, в Избранном или в любом диалоге.

Все команды начинаются с точки `.`.

### 1. Обычная рассылка (`.рассыл`)

**По интервалу времени:**
```text
.рассыл каждое 15 секунд promo
.рассыл каждые 10 минут promo
.рассыл каждый 1 час promo
.рассыл каждые 10 минут promo "Чаты Админов"
```

**По счетчику сообщений от других людей:**
```text
.рассыл через 1 promo
.рассыл через 3 promo "Папка Пиара"
```

**Как прикрепить текст и картинку к рассылке:**
- **Способ 1 (самый удобный)**: напиши красивый пост у себя в «Избранном» (с премиум-эмодзи, спойлерами, фотками или альбомом). Ответь на это сообщение командой:
  ```text
  .рассыл каждое 20 секунд реклама
  ```
- **Способ 2**: напиши команду на первой строке, а сам текст со второй строки:
  ```text
  .рассыл каждое 30 секунд реклама
  Куплю рекламу в каналах про крипту! Охват от 3к. Писать в ЛС @username
  ```

---

### 2. Рассылка постов из каналов (`.рассыл-пересланное`)

Когда нужно, чтобы в чаты шло сообщение именно в виде пересылки из твоего канала (со ссылкой на канал и глазками просмотров):

```text
.рассыл-пересланное каждое 30 секунд пост
.рассыл-пересланное через 2 пост "Моя Папка"
```

1. Отправляешь эту команду.
2. Бот пишет: `Режим сбора пересланных сообщений начат`.
3. Пересылаешь в этот чат пост (или несколько постов) из своего канала.
4. Пишешь команду `.закрыть` — бот сохраняет посты и сразу включает рассылку.
*(Если передумал — пиши `.отменить`).*

---

### 3. Рассылка пачки сообщений (`.рассыл-несколько`)

Если за один раз нужно отправить сразу текст, потом прайс-лист картинкой, а следом контакты:

```text
.рассыл-несколько каждое 15 минут пачка
.рассыл-несколько через 3 пачка "Админы"
```

1. Пишешь команду.
2. Отправляешь или пересылаешь нужные сообщения подряд.
3. Пишешь `.закрыть` — рассылка запущена.

---

### 4. Чередование постов по кругу (`.чередовать`)

Чтобы не долбить в чат один и тот же текст:

```text
.чередовать
пост1
пост2
пост3
```

Теперь каждый цикл рассылки в этом чате будет брать следующий шаблон: сначала `пост1`, потом `пост2`, потом `пост3`, а затем снова `пост1`.

---

### 5. Шпаргалка по командам

| Команда | Что делает |
|---|---|
| `.рассыл ...` | Обычная рассылка одного поста или альбома |
| `.рассыл-пересланное ...` | Запуск сбора пересланных сообщений из каналов |
| `.рассыл-несколько ...` | Запуск сбора пачки из нескольких сообщений |
| `.закрыть` | Завершить сбор и включить рассылку |
| `.отменить` | Сбросить текущий сбор |
| `.чередовать` | Задать очередь чередования постов в чате |
| `.стоп название` | Приостановить рассылку в этом чате |
| `.стоп название "папка"` | Приостановить рассылку для всех чатов в папке |
| `.стоп все` | Остановить все рассылки в чате |
| `.продолжить название` | Возобновить остановленную рассылку |
| `.продолжить все` | Возобновить все рассылки |
| `.удалить название` | Удалить рассылку и шаблон из базы |
| `.удалить все` | Полностью очистить все рассылки чата |
| `.просмотр название` | Прислать тестовый пост в чат (проверить медиа и разметку) |
| `.просмотр все` | Показать список активных рассылок и очередей в чате |
| `.инструкция` | Вывести справку прямо в Telegram |

## Автозапуск и работа 24/7

В папке `scripts/` уже лежат готовые скрипты:

### Windows:
- `scripts/run_windows_visible.bat` — запуск с окном консоли (для первого логина и кода).
- `scripts/run_windows_background.vbs` — тихий скрытый запуск (работает в фоне, окна нет).
- `scripts/install_autostart_windows.bat` — **автозапуск в 1 клик**: прописывает тихий старт в автозагрузку Windows. Комп включился — бот сам поднялся и работает.
- `scripts/stop_windows.bat` — быстро заглушить все запущенные процессы бота.
- `scripts/uninstall_autostart_windows.bat` — убрать из автозагрузки.

### Linux / VPS (Ubuntu/Debian):
- `sudo bash scripts/install_service_linux.sh` — ставит системную службу `systemd`. Бот будет крутиться в фоне, перезапускаться при сбоях и стартовать вместе с сервером.
- `bash scripts/status_linux.sh` — статус службы.
- `bash scripts/stop_linux.sh` — остановить службу.
- `sudo bash scripts/uninstall_service_linux.sh` — удалить службу.

### Android:

#### Вариант 1: Готовый APK (приложение для телефона)
Скачать готовый `.apk` можно в разделе **[Releases](https://github.com/Kleisym/spamblock-mailing/releases)**:
- Простой интерфейс: вводишь API ID, Hash, телефон, жмешь «Запустить 24/7».
- Работает через `Foreground Service` с постоянным уведомлением и блокировкой сна (`WakeLock`) — процессор не засыпает при выключенном экране.
- Сам перезапускается при перезагрузке смартфона (`BootReceiver`).
- Есть кнопка отключения оптимизации батареи, чтобы агрессивные оболочки (MIUI, OneUI, HyperOS) не выгружали процесс.
- В репозитории настроен GitHub Actions (`.github/workflows/build-apk.yml`) — при каждом пуше GitHub сам собирает свежий APK и выкладывает его во вкладку Releases.

#### Вариант 2: Через Termux
Если привычнее консоль:
```bash
bash scripts/install_android_termux.sh
```
Скрипт активирует `termux-wake-lock` и пропишет автозапуск через расширение `Termux:Boot`.
