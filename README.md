Telegram-юзербот для тех, кто активно работает в админских чатах, биржах рекламы и чатах взаимного пиара.

Полностью автоматизирует рутину: мгновенно глушит спам-уведомления от авто-ботов, автоматически проходит капчи и подписки на каналы, рассылает рекламные посты по гибким таймерам или счетчикам сообщений, поддерживает мульти-аккаунты, сохраняет 100% форматирование (Telegram Premium эмодзи, цитаты, медиа, альбомы, пересылки) и работает **24/7 даже после перезагрузки устройства**.

---

## ⚡ Главные возможности

1. **Тихий режим логов (`log_errors_only = true`)**:
   - В терминале отображается только красивый баннер старта и важные предупреждения/ошибки (FloodWait, недоступность чата).
   - Никакого спама счетчиков сообщений и рутинных логов в консоли.
2. **Мульти-аккаунт в одном процессе**:
   - Подключение неограниченного числа Telegram аккаунтов (`[account1]`, `[account2]`, etc.).
   - Все аккаунты работают параллельно в фоне, сохраняя общую базу шаблонов и изолированные очереди рассылок.
3. **Автозапуск 24/7 на всех платформах**:
   - **Windows**: готовые скрипты установки автозапуска в `%APPDATA%\Startup` (скрытый запуск без черного окна).
   - **Linux / Ubuntu**: готовая служба `systemd` с авто-перезапуском при падении и стартом при включении сервера.
   - **Android**:
     - **Готовое APK-приложение**: графический интерфейс, Foreground Service с постоянным уведомлением, защита от засыпания экрана (`WAKE_LOCK`), игнорирование оптимизации батареи и автозапуск при перезагрузке телефона (`BOOT_COMPLETED`).
     - **Termux**: скрипт автозапуска для `Termux:Boot`.
4. **Умный антиспам пингов**:
   - Распознает спам-ботов (NINJA, Jrvsu, скупка голды, NFT, тон, флаги с ценами) и сбрасывает статус упоминания на сервере Telegram (`clear_mentions`).
   - Телефон не вибрирует, а плашка `@` пропадает моментально.
   - **Реальные покупатели не глушатся**: вопросы вроде *"почем реклама?"*, *"актуально?"*, *"стата?"* остаются непрочитанными.
5. **Авто-прохождение капчи админ-ботов**:
   - Бот сам подписывается на каналы/ботов по требованию капчи, мьютит их навсегда, переносит в папку `автосабнутое` и нажимает кнопку верификации.
6. **Продвинутый рассыльщик рекламы**:
   - Рассылка по времени (`каждое 15 секунд`, `каждые 10 минут`, `каждый 1 час`).
   - Рассылка по счетчику живых сообщений (`через 3 сообщения`).
   - Рассылка по папкам чатов Telegram (`"Админы"`).
   - Рассылка пересланных постов из каналов (`.рассыл-пересланное`).
   - Рассылка пачки из 2 и более сообщений сразу (`.рассыл-несколько`).
   - Ротация и чередование постов по кругу (`.чередовать`).
   - Поддержка Telegram Premium эмодзи, цитат, спойлеров, медиа и альбомов.

## 🔑 Как получить API ID и API Hash

Для подключения к Telegram API нужны бесплатные ключи разработчика:

1. Откройте сайт: **[my.telegram.org](https://my.telegram.org)**.
2. Введите свой номер телефона (в международном формате, например `+79991234567`) и подтвердите код из приложения Telegram.
3. Выберите пункт **API development tools**.
4. Введите любые названия на английском:
   - **App title**: например `Spambuster`
   - **Short name**: например `spambuster`
5. Нажмите кнопку **Create application**.
6. Скопируйте поля **App api_id** и **App api_hash** в файл `config.txt`.

## 🛠 Быстрый старт (ПК: Windows / Linux / macOS)

### 1. Клонирование и установка зависимостей

```bash
git clone https://github.com/your-username/tg-spambuster.git
cd tg-spambuster

# Создание виртуального окружения
python -m venv venv

# Активация окружения:
# Windows:
venv\Scripts\activate
# Linux / macOS:
source venv/bin/activate

pip install -r requirements.txt
```

### 2. Настройка `config.txt`

Скопируйте `config.example.txt` в `config.txt`:

```bash
# Windows
copy config.example.txt config.txt

# Linux / macOS
cp config.example.txt config.txt
```

#### Вариант А: Один аккаунт

```ini
log_errors_only = true

api_id = 12345678
api_hash = 0123456789abcdef0123456789abcdef
phone = +79991234567

session_name = session_userbot
auto_sub_folder = автосабнутое
auto_read_spam_pings = true
auto_sub_enabled = true
```

#### Вариант Б: Несколько аккаунтов одновременно

```ini
log_errors_only = true

[account1]
api_id = 12345678
api_hash = 0123456789abcdef0123456789abcdef
phone = +79991112233
session_name = session_acc1
auto_sub_folder = автосабнутое
auto_read_spam_pings = true
auto_sub_enabled = true

[account2]
api_id = 87654321
api_hash = fedcba9876543210fedcba9876543210
phone = +79994445566
session_name = session_acc2
auto_sub_folder = автосабнутое
auto_read_spam_pings = true
auto_sub_enabled = true
```

### 3. Первый запуск и авторизация

```bash
python bot.py
```

- Введите код подтверждения из Telegram.
- Если включена двухфакторная аутентификация (2FA / облачный пароль), бот безопасно запросит пароль (ввод скрыт).
- После входа создаются файлы сессий `.session`. Повторно вводить данные больше никогда не потребуется.

## 📱 Приложение на Android (APK)

В репозитории есть готовый Android-проект (`android/`).

### Возможности APK:
- Удобный графический интерфейс для ввода API ID, Hash, телефона и пароля 2FA.
- **Работа 24/7 в фоне**: приложение запускает `Foreground Service` со встроенным `WAKE_LOCK`.
- **Автозапуск при перезагрузке**: компонент `BootReceiver` моментально восстанавливает фоновую службу при старте телефона.
- Кнопка отключения оптимизации батареи (`REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`), предотвращающая закрытие системой MIUI, HyperOS, OneUI и EMUI.

### Как получить APK:
1. **Через GitHub Actions (автоматическая сборка)**:
   - Перейдите во вкладку **Actions** в репозитории на GitHub.
   - Выберите workflow **Build Android APK** и нажмите **Run workflow** (или сделайте push).
   - Скачайте готовый `spambuster-debug-apk` из блока **Artifacts**.
2. **Локальная сборка на ПК**:
   ```bash
   cd android
   ./gradlew assembleDebug
   # Готовый APK будет в: android/app/build/outputs/apk/debug/app-debug.apk
   ```

## 🚀 Настройка 24/7 автозапуска на ПК и Серверах

В папке `scripts/` находятся готовые скрипты:

### Windows:
- `scripts/run_windows_visible.bat` — запуск с открытым окном консоли (для первого логина или отладки).
- `scripts/run_windows_background.vbs` — тихий скрытый запуск в фоне (без черных окон).
- `scripts/install_autostart_windows.bat` — **установка автозапуска в 1 клик**: копирует запуск в автозагрузку Windows. Бот будет работать постоянно и автоматически включаться при каждом старте ПК.
- `scripts/uninstall_autostart_windows.bat` — удаление из автозагрузки.
- `scripts/stop_windows.bat` — остановка всех фоновых процессов бота.

### Linux / Ubuntu (Systemd Service):
- `sudo bash scripts/install_service_linux.sh` — регистрирует и активирует системную службу `systemd`. Бот будет работать в фоне, перезапускаться при падении и запускаться при включении сервера.
- `bash scripts/status_linux.sh` — просмотр статуса службы.
- `bash scripts/stop_linux.sh` — остановка службы.
- `sudo bash scripts/uninstall_service_linux.sh` — удаление службы.

### Android Termux (Termux:Boot):
- `bash scripts/install_android_termux.sh` — настраивает скрипт для расширения `Termux:Boot`, активирует `termux-wake-lock` и держит бота запущенным в фоне без засыпания экрана.

## 💬 Команды управления в Telegram

Все команды пишутся в любом чате с аккаунта, на котором запущен юзербот. Все команды начинаются с точки `.`.

### 1. Обычная рассылка (`.рассыл`)

- **По времени**:
  ```text
  .рассыл каждое 15 секунд promo
  .рассыл каждые 10 минут promo
  .рассыл каждый 1 час promo
  .рассыл каждые 10 минут promo "Папка чатов"
  ```
- **По счетчику сообщений**:
  ```text
  .рассыл через 1 promo
  .рассыл через 3 promo "Папка чатов"
  ```
- **Как прикрепить текст и медиа**:
  - Ответьте командой на готовое сообщение (с медиа, альбомом, цитатами или эмодзи).
  - Или напишите команду на первой строке, а сам текст со второй строки:
    ```text
    .рассыл каждое 20 секунд реклама
    Куплю каналы от 10к подписчиков! Писать в ЛС @username 🚀
    ```

### 2. Рассылка пересланных сообщений (`.рассыл-пересланное`)

Рассылает посты с сохранением оригинальной плашки пересылки из канала (счетчик просмотров, кликабельная ссылка на канал-источник):

```text
.рассыл-пересланное каждое 30 секунд пост
.рассыл-пересланное каждые 15 минут пост "Моя Папка"
```

1. Отправьте команду в чат.
2. Бот откроет сессию сбора. Пересылайте нужные посты в чат.
3. Отправьте команду:
   ```text
   .закрыть
   ```
   Бот зафиксирует посты и запустит рассылку. Для отмены отправьте `.отменить`.

### 3. Рассылка пачки сообщений (`.рассыл-несколько`)

Отправляет 2 и более сообщений за один цикл (например, текст + прайс-лист + фото):

```text
.рассыл-несколько каждое 15 секунд пакет
.рассыл-несколько через 2 пакет "Моя Папка"
```

1. Отправьте команду.
2. Отправляйте любые сообщения подряд.
3. Отправьте `.закрыть` для старта рассылки.

### 4. Чередование шаблонов (`.чередовать`)

Позволяет отправлять разные посты по очереди:

```text
.чередовать
пост1
пост2
пост3
```

Каждый цикл рассылки будет брать следующий пост по кругу: `пост1 ➔ пост2 ➔ пост3 ➔ пост1`.

### 5. Управление рассылками

| Команда | Английский аналог | Действие |
|---|---|---|
| `.стоп название` | `.stop name` | Приостановить рассылку в этом чате |
| `.стоп название "папка"` | `.stop name "folder"` | Приостановить рассылку во всей папке |
| `.стоп все` | `.stop all` | Остановить все рассылки в этом чате |
| `.продолжить название` | `.resume name` | Возобновить рассылку |
| `.продолжить все` | `.resume all` | Возобновить все рассылки в чате |
| `.удалить название` | `.delete name` | Удалить рассылку и шаблон из базы |
| `.удалить все` | `.delete all` | Удалить все рассылки чата |
| `.просмотр название` | `.view name` | Отправить предпросмотр поста со всеми медиа и стилями |
| `.просмотр все` | `.view all` | Показать список активных рассылок и очередей в чате |
| `.инструкция` | `.help` | Вывести интерактивную справку прямо в Telegram |
